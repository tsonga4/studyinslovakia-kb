# Library — Knižnica

The main library for medical students is:

**Lekárska knižnica — Medical Library**

- 📍 Trieda SNP 1, Košice
- 📞 +421 55 234 1619

UPJŠ University Library services are available to registered users with a valid
user card. Students normally register using their ISIC/student card. The library
provides loans, in-library study, catalogues, renewals, reservations and return
boxes.

Library website: <https://www.upjs.sk/pracoviska/univerzitna-kniznica/en/>

## How to borrow books

1. Register at the library with your ISIC/student card.
2. Search for books in the electronic catalogue.
3. Check whether the book is available for home loan or only in-library use.
4. Borrow the book at the correct branch.
5. Return it before the deadline.
6. If possible, extend the loan once through the catalogue, by email, phone or in person.

UPJŠ states that loan periods can be extended once, unless the item has already
been extended or reserved by another user. Late returns are subject to fees.

## Fees and penalties

UPJŠ library fee documents list several fees, including late return fees,
one-day registration and other service fees. The official price list shows late
return fees and administrative fees for damaged, lost or late items.
