# What to pack

A quick checklist so you arrive prepared for the Slovak seasons and student life.

## Documents (carry in hand luggage)

- [ ] Passport / ID card
- [ ] Admission letter and any visa documents
- [ ] Health insurance papers
- [ ] A few passport photos (needed for local paperwork)

## Clothing

Slovakia has four distinct seasons — cold winters (well below 0 °C) and warm
summers. Bring layers and a proper winter coat.

## Good to know

!!! tip "Plug type"
    Slovakia uses **Type E** sockets, 230 V. Bring an adapter if your devices
    use a different plug.
